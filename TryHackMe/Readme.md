
Welcome to my **TryHackMe Write-ups** repository.

This repository documents my hands-on learning journey through TryHackMe rooms as I work toward becoming a **Security Operations Center (SOC) Analyst**.

The goal of this repository is **not** to provide room answers or walkthroughs. Instead, it serves as a collection of professional investigation notes, technical documentation, and lessons learned while completing labs and security challenges.

## Objectives

- Strengthen practical cybersecurity skills
- Develop a structured investigation methodology
- Practice documenting security incidents professionally
- Build a public portfolio of hands-on experience
- Continuously improve analytical and incident response skills

## What Each Write-up Includes

Each room typically contains:

- Room overview
- Investigation methodology
- Tools used
- Evidence and screenshots
- Network or host artifacts
- Indicators of Compromise (IOCs)
- MITRE ATT&CK mappings (where applicable)
- Detection opportunities
- Remediation recommendations
- Lessons learned

## Documentation Philosophy

Every write-up is created from the perspective of a security analyst investigating an incident. The emphasis is on:

- Analytical thinking
- Investigation workflow
- Technical observations
- Professional documentation

Rather than simply recording answers, I aim to explain **how** the investigation was performed and **why** each finding is important.

## Disclaimer

These write-ups are based on educational labs available on TryHackMe. They are intended for learning, portfolio development, and knowledge sharing. Room flags, direct answers, or copyrighted content are intentionally omitted to respect the platform and encourage independent learning.
